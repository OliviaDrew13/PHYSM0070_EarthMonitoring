- https://cjes.guilan.ac.ir/article_7977.html, https://cjes.guilan.ac.ir/article_7977_aa0ac1b21d0f849b4091619980af1349.pdf, Uncovering the hidden patterns of fire risks: A cluster analysis approach (K-Medoids and FCM) for Hyrcanian Forest in Iran
- used a clustering based model, multilayer perceptron artificial neural network with backpropagation
- used and compared two unsupervised clustering-specific procedures: Fuzzy C-Means (fully unsupervised), k-Medoids (supervised) (FCM, KM)
- forecasting fire prone areas
- doesn't include things like temperature and rainfall
- evaluated using RMSE, R^2, MSE
- high accuracy at predicting fire hazards
- three primary criteria: environmental, climactic and human factors
- ten sub-criteria
- uses Pearson correlation coefficient to help ID the most valuable factors to include
- allows for learning without pre-existing labels and minimal supervision
- Three layers, 10 input nodes, 5 mid nodes, 1 final node
- lots of context on the implementation of K-Medioids, can be intensive on large datasets but there are algorithms to help with that
- FCM is particularly good for cases where the boundaries btwn clusters are not well defined, soft assignments to multiple clusters
- has a Pearson correlation coefficient analysis table, can help with choice of environmental variable
- does produce a confusion matrix
- uses distance from cluster centre to define risk
